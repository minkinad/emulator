# План развития

Проект разделён на независимые модули: модель процессора, ассемблер и интерфейс. Ниже указаны доступные возможности и оставшиеся части реализации.

| Этап | Результат | Статус |
| --- | --- | --- |
| 1. Документация | Адаптивный сайт, светлая и тёмная темы, поиск, публикация GitHub Pages. | Готово |
| 2. Спецификация | Компоненты машины, форматы инструкций, адресация, флаги и алгоритмы массивов. | Готово |
| 3. Ядро CPU | Машинный кодек, АЛУ, память, шаг, ограниченное выполнение, загрузка и сброс. | Готово |
| 4. Ассемблер | Разбор исходников, два прохода для меток, машинный образ, карта строк и диагностика. | Готово |
| 5. Интерфейс | React + Vite: редактор, сборка, шаг/запуск/пауза, регистры и память. | Готово |
| 6. Программы массивов | Интеграция суммы и скалярного произведения, проверки данных, промежуточных состояний и результатов. | Готово |
| 7. Отчёт | Описание реализации, машинные листинги и воспроизводимые сценарии демонстрации. | Запланирован |

## Доступно сейчас

`npm run assembler:demo` собирает текстовую программу и исполняет её через CPU. `npm run core:demo` демонстрирует ручные машинные слова. API позволяет подключить редактор или другую оболочку без изменения ядра.

Тесты проверяют семантику команд, ограничение разрядности, переносы, границы памяти, остановку и ошибки. Ассемблер проверяется на ручных кодах, прямых и обратных метках, всех способах адресации и диагностике с номером строки. Программы массивов проверяются на сборку, адреса переходов, итоговые и промежуточные результаты, граничные данные, переносы, сброс и неверные длины. `npm run arrays:demo` печатает оба машинных листинга и проверяет результаты на CPU.

## Следующий этап: отчёт

Подготовка отчёта о фактической реализации: компоненты машины, форматы и семантика команд, обе программы в ассемблере и машинных кодах, сценарии демонстрации и заключение. Проверенные листинги и наборы данных уже доступны в [руководстве по программам](../architecture/programs.md).

[Браузерный интерфейс](application.md) уже поддерживает редактирование, сборку, шаги, запуск порциями, паузу, лимит, сброс и просмотр двух блоков памяти. Тесты проверяют одинаковые результаты шагов и непрерывного запуска, отмену отложенных команд, ошибки сборки и CPU, темы и мобильную вёрстку.

Подробности модулей: [ядро](../architecture/core-api.md), [ассемблер](../architecture/assembler.md), [структура проекта](structure.md).
