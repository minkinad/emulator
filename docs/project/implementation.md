# План развития

Проект разделён на независимые модули: модель процессора, ассемблер и интерфейс. Ниже указаны доступные возможности и оставшиеся части реализации.

| Этап | Результат | Статус |
| --- | --- | --- |
| 1. Документация | Адаптивный сайт, светлая и тёмная темы, поиск, публикация GitHub Pages. | Готово |
| 2. Спецификация | Компоненты машины, форматы инструкций, адресация, флаги и алгоритмы массивов. | Готово |
| 3. Ядро CPU | Машинный кодек, АЛУ, память, шаг, ограниченное выполнение, загрузка и сброс. | Готово |
| 4. Ассемблер | Разбор исходников, два прохода для меток, машинный образ, карта строк и диагностика. | Готово |
| 5. Интерфейс | React + Vite: редактор, сборка, шаг/запуск/пауза, регистры и память. | Запланирован |
| 6. Программы массивов | Интеграция суммы и скалярного произведения, полный набор проверок данных и результатов. | Запланирован |
| 7. Отчёт | Описание реализации, машинные листинги и воспроизводимые сценарии демонстрации. | Запланирован |

## Доступно сейчас

`npm run assembler:demo` собирает текстовую программу и исполняет её через CPU. `npm run core:demo` демонстрирует ручные машинные слова. API позволяет подключить редактор или другую оболочку без изменения ядра.

Тесты проверяют семантику команд, ограничение разрядности, переносы, границы памяти, остановку и ошибки. Ассемблер проверяется на ручных кодах, прямых и обратных метках, всех способах адресации и диагностике с номером строки. Листинги массивов проверяются на сборку и адреса переходов; полная интеграционная проверка алгоритмов остаётся отдельной задачей.

## Следующий этап: браузерный интерфейс

Редактор должен передавать текст ассемблеру и загружать только успешно собранный образ. Шаг и непрерывный запуск используют один `step()`. Выполнение порциями сохраняет отзывчивость страницы; доступны пауза, лимит команд и сброс.

Состояние отображается с подписями: регистры, флаги, следующий `PC`, адрес и машинное слово выбранной инструкции, её ассемблерное представление и поля. Карта исходных строк связывает машинный адрес с редактором. Команды и данные отображаются как разные блоки памяти.
