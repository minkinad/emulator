# Emulator 1.0.0

Первый выпуск браузерного эмулятора процессора: от исходника на ассемблере до пошагового исполнения машинного кода.

## Возможности

- 16-битный процессор с гарвардской архитектурой, 16 регистрами и 17 командами фиксированной длины 32 бита.
- Ассемблер с метками, четырьмя способами адресации и диагностикой ошибок на русском языке.
- Редактор программ, загрузка данных, сборка, шаг, запуск, пауза, лимит команд и сброс.
- Просмотр PC, IR, флагов, регистров, раздельной памяти команд и данных; декодирование инструкции и подсветка изменений.
- Пять примеров, включая 32-битную сумму массива и 48-битную свёртку десяти пар с длинной арифметикой внутри CPU.
- Светлая и тёмная темы, горячие клавиши и адаптация к мобильному экрану.
- Независимые TypeScript-модули ядра и ассемблера, консольные примеры, документация API и PDF отчёта без титульного листа.

## Запуск

[Открыть эмулятор](https://minkinad.github.io/emulator/app/) · [Документация](https://minkinad.github.io/emulator/)

Для локального запуска нужны Node.js 22.12+ и npm:

```bash
npm ci
npm run dev
```

Откройте адрес Vite с путём `/emulator/app/`. Программы исполняются в браузере; исходник и данные не отправляются на сервер.

## Ограничения

- Стек, прерывания и директивы ассемблера не реализованы.
- Автоматического сохранения программы и данных нет: при перезагрузке они сбрасываются; сохраняется тема.
- Пример суммы рассчитан на 0…15 элементов; пример свёртки требует ровно 10 элементов в каждом массиве.

PDF отчёта приложен к релизу как `emulator-report.pdf`.
