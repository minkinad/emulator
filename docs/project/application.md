# Браузерный эмулятор

Рабочая область объединяет редактор ассемблера, управление процессором и просмотр состояния. Оформление использует системные шрифты, скруглённые панели и светлую/тёмную темы в стиле SwiftUI.

[Открыть приложение](https://minkinad.github.io/emulator/app/). Для локального запуска нужны Node.js 22.12+ и npm:

```bash
npm ci
npm run dev
```

Откройте напечатанный Vite адрес с путём `/emulator/app/`. Для проверки производственной сборки выполните `npm run app:build`, затем `npm run preview`.

## Первая программа

При открытии уже собран пример «Сумма в цикле». Нажимайте **Шаг**, чтобы наблюдать отдельные команды, или **Запуск**, чтобы выполнить программу. После `HALT` регистр R0 и ячейка данных `0x0300` содержат 6.

Список примеров также содержит загрузку и сложение двух значений из памяти и перенос между словами через `ADD` / `ADC`. Выбор примера заменяет редактор и начальные данные, собирает программу и сбрасывает машину.

## Программы массивов

В списке примеров доступны **Сумма массива · 32 бита** и **Свёртка массивов · 48 бит**. Выбор загружает исходник и данные. Для суммы результат по умолчанию — `−5`, для свёртки — `10737418240`. Эти вычисления выполняются командами CPU в цикле.

После `HALT` отдельная панель показывает итог как знаковое десятичное число и два или три слова памяти. При паузе и после сброса итог ещё не объявляется готовым. Если изменён исходник программы, специализированная панель скрывается; регистры и память остаются доступны. Начальные данные можно менять и собирать заново.

В `0x0100` хранится длина A, элементы начинаются с `0x0101`. Сумма рассчитана на длину `0…15`; основная демонстрация использует 10 элементов. В `0x0200` находится длина B, элементы — с `0x0201`. Свёртка требует обе длины, равные 10; иначе пишет статус 1 в `0x0303` и сохраняет прежний результат. Отсутствующие ячейки заполнены нулями, поэтому все нужные элементы следует указывать явно.

Подробности, исходники и контрольные наборы: [программы массивов](../architecture/programs.md).

## Редактор и начальные данные

Исходник использует [синтаксис ассемблера](../architecture/assembler.md). После изменения текста или данных нажмите **Собрать** либо `Ctrl+Enter` / `⌘+Enter`. До новой сборки исполнение недоступно. Ошибка показывает строку и позицию; **К ошибке** переводит курсор в нужное место. Неудачная сборка сохраняет ранее загруженную машину.

Начальные данные задаются отдельно от команд:

```text
; Адрес первой ячейки: последовательность значений
0x0100: -7, 12, 0xFFFF
768: 0
```

Адреса — десятичные или шестнадцатеричные числа от 0 до 4095. Значения — знаковые десятичные числа от −32768 до 32767 либо 16-битные hex-слова `0x0000…0xFFFF`. Значения после запятой занимают следующие ячейки. Повторные адреса и выход за границу памяти вызывают ошибку. Пустые строки и комментарии `;` допустимы; остальные ячейки заполнены нулями.

Успешная сборка загружает новый образ и обнуляет регистры, флаги и счётчик команд. **Сброс** восстанавливает последний успешно загруженный образ, включая начальные данные; несобранные изменения редактора сохраняются. Во время запуска редактирование заблокировано.

## Выполнение

| Управление | Поведение |
| --- | --- |
| Шаг | Одна выборка, декодирование и исполнение машинного слова. |
| Запуск | Последовательность тех же шагов с передачей управления браузеру. |
| Пауза | Остановка перед следующей порцией команд, без потери состояния. |
| Скорость | Примерно 1 или 10 команд в секунду; «Быстро» — до 250 команд за порцию. Скорость зависит от браузера. |
| Лимит | От 1 до 1000000 команд за один запуск, по умолчанию 100000. Достижение лимита ставит выполнение на паузу; запуск можно продолжить. |
| HALT / ошибка CPU | Прекращение исполнения. Для нового запуска нужны сброс или сборка. |

В быстром режиме экран обновляется после порции; подсвечиваются все изменённые за неё ячейки и регистры. Чтобы изучить каждую команду, используйте шаги. Интерфейс не исполняет исходные строки напрямую: ассемблер создаёт машинные слова, CPU читает их из памяти команд.

## Состояние и память

Панель инструкции показывает адрес последней выбранной команды, слово `IR`, ассемблер, формат и поля. `PC` обозначает адрес **следующей** команды. Ниже доступны все 16 регистров и флаги `ZF`, `NF`, `CF`, `OF`. Значения регистров и данных представлены в hex и знаковом десятичном виде.

Вкладки **Команды** и **Данные** показывают независимые адресные пространства. Адрес просмотра принимает decimal или hex; стрелки листают ячейки. **К PC** открывает следующую команду, **К данным** — адрес `0x0100`, **К результату** — `0x0300`. В таблице команд можно перейти к исходной строке. Синий фон отмечает последнюю выбранную команду, стрелка — следующий PC.

R0 и R3 — обычные регистры. Подписи «Аккумулятор» и «Счётчик» отражают соглашение примера с циклом, а не ограничения процессора.

## Хранение и доступность

Вычисления выполняются локально в браузере. Исходник и данные не отправляются на сервер; перезагрузка страницы возвращает начальный пример. Сохраняется только выбранная тема. Элементы доступны с клавиатуры, есть переход к рабочей области, видимый фокус и адаптация к узким экранам.

Исходники, машинные листинги и проверки обеих программ доступны в репозитории; оставшиеся задачи перечислены в [плане развития](implementation.md).
