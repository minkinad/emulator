# История изменений

Здесь фиксируются выполненные изменения проекта. Новые записи добавляются в `Unreleased` в подходящую категорию; последние выпуски располагаются первыми. При выпуске записи переносятся в раздел `## [X.Y.Z] — YYYY-MM-DD`, а `Unreleased` остаётся для следующей работы. До первого выпуска номер версии не назначен.

Категории: `Added` — добавлено, `Changed` — изменено, `Deprecated` — объявлено устаревшим, `Removed` — удалено, `Fixed` — исправлено, `Security` — изменения безопасности. Пустые категории можно оставить в заготовке и убрать при выпуске. Будущие задачи здесь не считаются выполненными.

## [Unreleased]

### Added

- План поэтапной реализации варианта 7 с критериями готовности, коммитами в `main` и обязательным запросом продолжения после каждого этапа.
- Сайт документации на VitePress: главная со схемой процессора, русская навигация, поиск, светлая/тёмная темы и адаптивная вёрстка.
- Сборка страниц из существующих Markdown-файлов и инструкция локального запуска сайта.
- Workflow сборки сайта в pull request и публикации GitHub Pages из `main`.
- Обзор требований к эмулятору и отчёту, идеи архитектуры, этапы разработки и список вопросов к заданию в README.
- Разбор всех 16 вариантов с рекомендациями и распределением работы на трёх разработчиков в `docs/variants.md`.
- Инструкции для агентов в корневом `AGENTS.md`.
- Базовые файлы `.github/`: правила участия, шаблоны задач, ошибок и pull request, workflow проверки оформления документации.
- Структура истории изменений с категориями и правилами оформления выпусков.

### Changed

- Этап 1: документация переоформлена в стиле SwiftUI — системная типографика, синий акцент, сгруппированные карточки, полупрозрачная навигация, светлая/тёмная темы; схема процессора адаптирована к обеим темам и узким экранам. Добавлены видимый фокус клавиатуры и поддержка уменьшения движения.
- Зафиксирован согласованный стек браузерного эмулятора: TypeScript + React + Vite; правила работы обновлены под последовательное выполнение этапов.
- Главная, навигация и схема процессора переведены на вариант 7: показаны два блока памяти и пример трёхадресной команды `ADD R0, R1, R2`.
- Инструкции для агентов и участников разработки согласованы с вариантом 7: раздельная память и знаковая длинная арифметика.
- После переназначения на вариант 7 обновлены README и описание задания: трёхадресная гарвардская машина, сумма знакового массива и свёртка двух массивов по 10 элементов; уточнены проверки знакового расширения и длинного результата.
- Зафиксирован выбранный командой вариант 10: двухадресная машина фон Неймана, максимум и свёртка беззнаковых массивов с длинной арифметикой.
