# История изменений

Изменения проекта до первого выпуска. Новые возможности и исправления записываются в `Unreleased`; при выпуске переносятся в раздел с номером версии и датой.

## [Unreleased]

### Added

- Ассемблер: два прохода для меток, все 17 инструкций, четыре способа адресации, контроль диапазонов, машинный образ и карта исходных строк.
- Диагностика сборки на русском языке с кодом ошибки, строкой и позицией; ошибочная сборка не возвращает частичный образ.
- Ассемблерный пример с циклом и команда `npm run assembler:demo`.
- Тесты ассемблера: ручные машинные коды, метки вперёд и назад, синтаксис, граничные значения, диагностика, сборка листингов массивов и исполнение примера на CPU.
- Независимое ядро CPU на TypeScript: кодек, АЛУ, флаги, раздельная память, атомарное пошаговое исполнение, ограниченный запуск, загрузка и сброс.
- Проверки ядра с независимым bigint-эталоном и пример ручных машинных слов `npm run core:demo`.
- Документация спецификации, API модулей, алгоритмов массивов и структуры проекта; справочный разбор всех 16 вариантов архитектуры.
- Сайт VitePress с поиском, светлой/тёмной темами, адаптивной вёрсткой, клавиатурной навигацией и поддержкой уменьшения движения.
- GitHub Actions для проверки модулей, документации и публикации сайта на GitHub Pages.
- Шаблоны задач и pull request, правила участия и инструкции для автоматизированной работы с репозиторием.

### Changed

- Документация приведена к публичному виду: быстрый старт, синтаксис, API и описание доступных возможностей вместо указаний для конкретной команды и маркировки назначенного варианта.
- Справочник вариантов сохранён без выделения выбранной конфигурации; требования реализованной машины остаются в технической спецификации.
- Тестовый запуск очищает только `.test-build/`, компилирует и находит тесты всех модулей; CI выполняет машинный и ассемблерный примеры.
- Исходники документации разделены на `docs/architecture/`, `docs/project/` и `docs/reference/`; адреса основных опубликованных страниц сохранены.
- Оформление сайта использует системную типографику, синий акцент, скруглённые поверхности и полупрозрачную навигацию в стиле SwiftUI.
- Генератор страниц удаляет устаревшие копии из своих выходных каталогов перед сборкой.

### Removed

- Служебная страница AGENTS из публичного сайта, навигации, поиска и карты сайта. Корневой файл инструкций сохранён в репозитории.
