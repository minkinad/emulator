# История изменений

Изменения проекта до первого выпуска. Новые возможности и исправления записываются в `Unreleased`; при выпуске переносятся в раздел с номером версии и датой.

## [Unreleased]

### Added

- Отчёт без титульного листа: задание, компоненты процессора, форматы и семантика всех 17 команд, реализация, полный ассемблер и машинные коды обеих программ, контрольные результаты и заключение.
- Протокол демонстрации суммы, свёртки, переноса через два слова, отрицательного результата, неверной длины и диагностики.
- Проверка соответствия четырёх листингов отчёта исходным файлам при сборке документации.
- Экспорт PDF A4 с нумерацией страниц, читаемыми листингами и ссылками; PDF добавляется в артефакт Pages отдельным шагом.

- Две программы массивов в `.asm`: 32-битная сумма и 48-битная свёртка десяти пар с длинной арифметикой внутри CPU.
- Каталог примеров для браузера, готовые машинные листинги и команда `npm run arrays:demo` с проверкой результатов.
- Панель итогового знакового числа и слов памяти; неверная длина свёртки отображается отдельно от результата.
- Интеграционные проверки граничных и случайных данных, каждой частичной суммы, расширения знака, переносов, неизменности входов, сброса и продолжения между ADD/ADC.
- Проверка согласованности `.asm`, сгенерированного модуля, документации и машинных листингов; CLI массивов включён в CI.

- Браузерный интерфейс React + Vite: редактор, начальные данные, сборка, шаги, запуск порциями, пауза, лимит и сброс.
- Просмотр машинного слова, ассемблера, полей инструкции, PC, IR, флагов, всех регистров и обоих адресных пространств; подсветка изменений и связь с исходными строками.
- Три коротких примера, диагностика с переходом к строке, светлая/тёмная темы, клавиатурное управление и мобильная вёрстка в стиле SwiftUI.
- Проверки модели сеанса и браузерные сценарии Playwright для выполнения, ошибок, паузы, границ памяти и оформления.

- Ассемблер: два прохода для меток, все 17 инструкций, четыре способа адресации, контроль диапазонов, машинный образ и карта исходных строк.
- Диагностика сборки на русском языке с кодом ошибки, строкой и позицией; ошибочная сборка не возвращает частичный образ.
- Ассемблерный пример с циклом и команда `npm run assembler:demo`.
- Тесты ассемблера: ручные машинные коды, метки вперёд и назад, синтаксис, граничные значения, диагностика, сборка листингов массивов и исполнение примера на CPU.
- Независимое ядро CPU на TypeScript: кодек, АЛУ, флаги, раздельная память, атомарное пошаговое исполнение, ограниченный запуск, загрузка и сброс.
- Проверки ядра с независимым bigint-эталоном и пример ручных машинных слов `npm run core:demo`.
- Документация спецификации, API модулей, алгоритмов массивов и структуры проекта; справочный разбор всех 16 вариантов архитектуры.
- Сайт VitePress с поиском, светлой/тёмной темами, адаптивной вёрсткой, клавиатурной навигацией и поддержкой уменьшения движения.
- GitHub Actions для проверки модулей, документации и публикации сайта на GitHub Pages.
- Шаблоны задач и pull request, правила участия и инструкции для автоматизированной работы с репозиторием.

### Changed

- README дополнен существующим логотипом, бейджами workflow и стека, реальными скриншотами, таблицей примеров, проверками и ограничениями. Ресурсы README доступны также на сайте документации.
- Актуализированы существующие CONTRIBUTING и шаблоны ошибок, задач и pull request: воспроизведение проблем CPU/UI/PDF, проверки по типу изменения и правила обновления листингов и скриншотов.

- Базовый план из семи этапов завершён; отчёт и протокол доступны в навигации, поиске и карте сайта.

- GitHub Pages собирает документацию и приложение в одном артефакте; приложение размещается по пути `/emulator/app/`.
- Исходники интерфейса разделены на компоненты и независимую модель; добавлены команды разработки, сборки и браузерных проверок. Минимальная версия Node.js — 22.12.

- Документация приведена к публичному виду: быстрый старт, синтаксис, API и описание доступных возможностей вместо указаний для конкретной команды и маркировки назначенного варианта.
- Справочник вариантов сохранён без выделения выбранной конфигурации; требования реализованной машины остаются в технической спецификации.
- Тестовый запуск очищает только `.test-build/`, компилирует и находит тесты всех модулей; CI выполняет машинный и ассемблерный примеры.
- Исходники документации разделены на `docs/architecture/`, `docs/project/` и `docs/reference/`; адреса основных опубликованных страниц сохранены.
- Оформление сайта использует системную типографику, синий акцент, скруглённые поверхности и полупрозрачную навигацию в стиле SwiftUI.
- Генератор страниц удаляет устаревшие копии из своих выходных каталогов перед сборкой.

### Removed

- Служебная страница AGENTS из публичного сайта, навигации, поиска и карты сайта. Корневой файл инструкций сохранён в репозитории.
